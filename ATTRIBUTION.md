## Cburnett Chess Pieces

This project includes chess piece artwork based on the **Cburnett**
chess piece set created by **Colin M. L. Burnett**.

The Cburnett set is widely used by chess software and websites,
including Lichess and Wikimedia projects.

### Author

Colin M. L. Burnett (Cburnett)

### Source

The chess piece artwork used by this project is based on the Cburnett
SVG chess piece set distributed by the Lichess project:

https://github.com/lichess-org/lila/tree/master/public/piece/cburnett

### Modifications

For use in this project, the original SVG chess piece artwork was:

1. converted to transparent PNG images;
2. resized for use in Google Sheets;
3. encoded as Base64 data and embedded in `Piezas.gs`.

One asset may contain minor graphical corrections made during the
conversion and preparation process.

These modifications do not change the copyright or licensing status
of the original artwork.
